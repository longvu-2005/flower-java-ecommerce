# Flower E-Commerce Website

## Tech Stack
- Backend: Java (Servlet/JSP), JDBC
- Database: SQL Server
- Frontend: HTML5, CSS3, JavaScript (ES6)
- IDE: NetBeans

## How to Run This Project
1. Clone this repository to your local machine.
2. Import the `database.sql` file into your SQL Server Management Studio (SSMS).
3. Open the project in NetBeans.
4. Configure the database connection string in your project (Database context/DAO class).
5. Run the project on Apache Tomcat Server.
